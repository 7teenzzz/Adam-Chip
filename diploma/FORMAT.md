# Правила форматирования дипломной работы

Документ описывает требования к оформлению перед экспортом в .docx.

| Начертание        | Полужирный                                  |
| Регистр           | С прописной буквы, остальные — строчные     |
| Выравнивание      | По ширине                                   |
| Отступ            | 1,25 см                                     |
| Точка в конце     | Нет                                         |
| Подчёркивание     | Нет                                         |

### 3.4. Общие правила для всех заголовков основной части

- Печатать с абзацного отступа 1,25 см, с прописной буквы, без точки в конце, без подчёркивания (остальные буквы строчные).
- Если заголовок состоит из двух предложений — разделять точкой.
- Если длинный заголовок переносится на следующую строку — начинать её также с отступа 1,25 см.
- Переносы слов внутри заголовков не допускаются.
- Интервал между заголовками разных уровней — 12 пт.
- Нельзя оставлять на предыдущей странице только заголовок без текста: в конце страницы должна быть хотя бы одна строка основного текста.

## 4. Интервалы между элементами

| Элемент                                              | Интервал до | Интервал после |
| ---------------------------------------------------- | ----------- | -------------- |
| Заголовок раздела → основной текст                   | —           | 12 пт          |
| Заголовок раздела → заголовок подраздела             | —           | 12 пт          |
| Рисунок (включая подпись) ↔ основной текст           | 12 пт       | 12 пт          |
| Формула ↔ основной текст                             | 12 пт       | 12 пт          |
| Таблица (включая название) ↔ основной текст          | 12 пт       | 12 пт          |

## 5. Кавычки

- Единственный допустимый вид кавычек — «ёлочки»: **«»**.
- Кавычки-лапки `""`, апострофные `''` и прямые `"` не допускаются нигде в тексте.
- Вложенные кавычки — «ёлочки» внутри «ёлочек»: «текст «вложение» текст».

---

## 6. Перечисления

- Перед каждым пунктом — тире (–), с абзацного отступа 1,25 см.
- В конце каждого пункта — точка с запятой (;).
- В конце последнего пункта — точка (.).

Пример:
```
– первый пункт перечисления;
– второй пункт перечисления;
– последний пункт перечисления.
```

---

## 7. Иллюстрации (рисунки)

- Нумерация сквозная арабскими цифрами (Рисунок 1, Рисунок 2, …).
- Иллюстрация размещается **без абзацного отступа** и выравнивается **по центру** строки.
- Подпись: слово «Рисунок», номер и наименование — **после** рисунка, по центру строки.
  - Пример: `Рисунок 3 — Архитектура системы`
- Если наименование занимает несколько строк — записывать через один межстрочный интервал.
- На каждую иллюстрацию должна быть ссылка в тексте: «…как показано на рисунке 3».
- Рисунок располагается непосредственно под текстом, в котором впервые дана ссылка на него.

---

## 8. Таблицы

- Располагается на всю ширину печатного поля.
- Помещается под текстом первой ссылки или на следующей странице.
- Название — над таблицей, **без абзацного отступа**, слева, формат:
  - `Таблица <Номер> — <Наименование>`
  - Пример: `Таблица 2 — Параметры конфигурации`
- Наименование — с прописной буквы, без точки в конце.
- Если наименование занимает две строки и более — записывать через один межстрочный интервал.
- Нумерация сквозная.

## 9. Ссылки на элементы работы

Формат ссылок в тексте:

| Тип элемента     | Формат ссылки                        |
| ---------------- | ------------------------------------ |
| Раздел           | «как описано в разделе 1»            |
| Подраздел/пункт  | «см. пункт 2.1.5»                    |
| Рисунок          | «как показано на рисунке 9»          |
| Таблица          | «в таблице 5»                      |
| Приложение       | «подробнее — см. приложение А»       |

---

## 10. Нумерация страниц

- Сквозная, арабскими цифрами.
- Размещение: нижний колонтитул, по центру.
- Титульный лист включается в нумерацию, но номер на нём не проставляется.

## 11. Список использованных источников

### 11.1. Порядок расположения

- Источники располагаются **в порядке появления ссылок** на них в тексте работы (не по алфавиту).
- Номер источника записывается **с абзацного отступа** (1,25 см).

### 11.2. Ссылки в тексте

- Номер источника выделяется **квадратными скобками**: `[1]`, `[25]`.
- Пример: «в соответствии с ГОСТ 2.111-68 [1]».
- Ссылки на структурные элементы работы: «как описано в разделе 1», «см. пункт 2.1.5», «как показано на рисунке 9», «в таблице 5», «подробнее — см. приложение А».

### 11.3. Книги (монографии, учебники, справочники)

Формат (≤ 3 авторов):
```
Фамилия И. О. Название книги. – Город: Издательство, Год.
```

Формат (> 3 авторов):
```
Название книги / И. О. Первый [и др.]. – Город: Издательство, Год.
```

Примеры:
```
Фокин М. Н., Жигалова К. А. Методы коррозионных испытаний металлов. – М.: Металлургия, 1986.
Производство и применение гнутых профилей проката / И. С. Триневский [и др.]. – М.: Металлургия, 1975.
```

### 11.4. Статьи в журналах и сборниках

Формат (≤ 3 авторов):
```
Фамилия И. О. Название статьи // Название журнала. – Год. – № N. – С. X–Y.
```

Формат (> 3 авторов):
```
Название статьи / И. О. Первый [и др.] // Название журнала. – Год. – № N. – С. X–Y.
```

### 11.5. Электронные ресурсы (сайты, онлайн-статьи)

Формат:
```
Автор И. О. Название материала // Название сайта / Организация. – URL: http://... (дата обращения: ДД.ММ.ГГГГ).
```

Примеры:
```
Адлер Ю. П. Восемь принципов, которые меняют мир // Металлсертификат / МИСиС. – URL: http://www.mc.misis.ru/news.html (дата обращения: 02.11.2008).
Статистика: Деятельность Федерального агентства... // Федеральное агентство по техническому регулированию и метрологии: официальный сайт. – URL: http://www.gost.ru (дата обращения: 12.02.2009).
```

### 11.6. Имена авторов

- Имена и фамилии авторов **русскоязычных источников** — на русском языке.
- Имена и фамилии авторов **иностранных публикаций** (arXiv, NeurIPS, журналы) — в оригинальной латинской транскрипции.
- Для иностранных авторов переводных изданий, изданных на русском языке, — **русская транслитерация**: «Хайдеггер М.», «Латур Б.», «Харауэй Д.».
- Инициалы указываются **после фамилии**: «Кант И.», «Vaswani A.» (не «И. Кант», не «A. Vaswani»).

### 11.7. Пунктуация в конце записи

- Каждая запись (кроме последней) заканчивается **точкой с запятой (;)**.
- Последняя запись в списке заканчивается **точкой (.)**.

### 11.8. Общие требования

- Сведения отделяются **тире с пробелами**: ` – `.
- Место издания сокращается стандартно: Москва → М., Санкт-Петербург → СПб.
- Год издания — без слова «год» и его сокращений: просто число.
- Объём книги (количество страниц) допускается не указывать.
