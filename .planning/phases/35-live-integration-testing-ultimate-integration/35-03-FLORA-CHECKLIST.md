## Главный тест — COEXISTENCE (сосуществование)

**Инструкция:**
1. Убедитесь, что флора в состоянии `breathe` (фоновая анимация идёт).
2. Скажите «**Адам, расскажи что-нибудь**».
3. **ВО ВРЕМЯ** ответа Адама смотрите на свет:
   - Должен перейти в `external` режим — свет мерцает в такт его речи (RMS-driven)
   - Яркость меняется с каждым слогом / паузой
4. **ПОСЛЕ** того как Адам замолчал — свет должен вернуться в `breathe`.

| Наблюдение | Результат |
|---|---|
| Свет перешёл из breathe в другой режим когда Адам начал говорить | [ ] ok / [ ] fail |
| Свет мерцает в такт речи (RMS) во время ответа | [ ] ok / [ ] fail / [ ] не заметно |
| После ответа свет вернулся в медленное дыхание (breathe) | [ ] ok / [ ] fail |
| Вибро во время ответа (должно быть активно в non-attentive режиме) | [ ] ok / [ ] fail / [ ] нет моторов |
