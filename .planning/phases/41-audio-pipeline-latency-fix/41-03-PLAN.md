With normal frame cadence restored (Plan 41-01) and code fixes in place (Plan 41-02), recalibrate OpenWakeWord and verify VAD/ASR endpointing timers behave at wall-clock scale.

While broken they stretched ~10x in wall-clock. Verify they now behave correctly — this is primarily a VERIFY task; only adjust a timer if live testing proves a value is wrong at normal cadence.

Purpose: Restore reliable wake-word activation and confirm the voice loop's timing is healthy.
Output: Recalibrated `wake_word.threshold`/`debounce_hits` in Config.json (Config-First; hot-reloadable via /api/config) + documented live VAD/ASR timer behavior.

PRECONDITION: This plan requires the orchestrator running with the voice loop active AND the user physically present to speak "адам". It is NOT autonomous.
