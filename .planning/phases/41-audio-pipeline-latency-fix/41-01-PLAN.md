<objective>
Activate the already-created WirePlumber latency override for the WebCamera USB microphone node and verify that PipeWire resumes continuous ~20ms frame delivery (~50 Hz). This is the root-cause fix: the node currently has `node.max-latency=48000/48000` (1s) and `buffer_size=96000` (2s @ 48kHz), causing audio to arrive in ~120ms bursts once per ~1.1-1.2s — only ~10% of real throughput reaches Python. That freezes `oww_score` at 0.001 and breaks VAD/ASR endpointing timers.

Purpose: Restore the audio throughput that all downstream calibration (Waves 2-3) depends on. Nothing else in this phase can be verified until frame cadence is normal.
Output: Active WirePlumber override + empirical confirmation of restored cadence via events.jsonl.

BRANCH NOTE: Current branch is `SmartFlora` (flora feature work) — this audio fix is scope-mismatched. Do NOT switch branches in plan tasks. Per ROADMAP Phase 41, commit/push must land on a separate branch (`audio-pipeline-fix` from `main`/`subconscious-symbiont`), handled at `/commit-push` time, not here. The override file lives in `~/.config/` (outside the repo) so it is not part of any commit.
</objective>
