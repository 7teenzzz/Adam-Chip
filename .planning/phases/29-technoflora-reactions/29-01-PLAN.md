<objective>
Build the ESP32-S3 firmware animation engine (FLORA-01) and its control endpoint
(FLORA-02). A dedicated FreeRTOS task runs a preset state machine
(`breathe`/`accent`/`attentive`/`think_pulse`/`wake_bloom`/`idle`), crossfades
between presets, applies a gamma LUT, and writes one frame per tick via
`writeAllChannelsRaw`. A new `POST /api/flora/state` handler swaps the active
preset. Light = channels 0-10, vibro = channels 11-14. Vibro is hard-zeroed when
preset==attentive (protects ASR from motor→mic coupling, D-11).

Purpose: the autonomous-on-ESP half of the hybrid architecture (D-03) — ambient
states survive Jetson HTTP jitter and tick smoothly at ~50 Hz locally.
Output: `FloraModule.cpp/.h`, a flora HTTP route, firmware structural defaults in
`AdamsConfig.h`, and a `startFloraTask()` call in `setup()`.
</objective>
