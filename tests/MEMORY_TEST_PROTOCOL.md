# Memory Test Protocol — Phase 30

Протокол ручного тестирования системы памяти (echoes/chinese gate).

**Что тестируем:** изменения ветки `MemoryFixes` — Phase 30 улучшения gate.

**Главный баг до фикса:** gate матчил теги против сырого транскрипта по подстроке.
Слово «одиноко» не является подстрокой тега «одиночество» → эхо никогда не всплывало.
Chinese pool был disabled outright.

**Phase 30 фикс:**
- Слой A: матч идёт против `{темы} ∪ {ключевые слова кластеров} ∪ {история диалога}`
- Слой B: мягкий взвешенный движок вместо жёсткого порога
- Слой C: спонтанный канал (5% вероятность всплытия без матча)
- Слой D: diversity — не повторять тематику внутри сессии

## Подготовка к тесту

### 1. Запустить оркестратор

```bash
PYTHONPATH=System ADAM_MODE=maintenance ./.venv/bin/python System/Orchestrator.py
```

### 2. Понизить cooldown для тестирования (иначе между инжектами нужно 12 ходов)

```bash
curl --noproxy '*' -X POST http://127.0.0.1:8080/api/tuning \
  -H 'Content-Type: application/json' \
  -d '{
    "echoes": {
      "global_cooldown_turns": 2,
      "per_echo_cooldown_days": 0,
      "spontaneous_probability": 0.5,
      "spontaneous_min_turns": 1
    },
    "chinese": {
      "global_cooldown_turns": 2,
      "per_echo_cooldown_days": 0,
      "spontaneous_probability": 0.3,
      "spontaneous_min_turns": 1
    }
  }'
```

### 3. Включить trace_prompts (видим полный prompt в WebUI /metrics)

```bash
curl --noproxy '*' -X POST http://127.0.0.1:8080/api/tuning \
  -H 'Content-Type: application/json' \
  -d '{"diagnostics": {"trace_prompts": true}}'
```

### 4. Открыть мониторинг событий в отдельном терминале

```bash
# Live tail событий (echo_injected появится в каждом turn где сработало эхо)
watch -n1 "curl --noproxy '*' -fsS 'http://127.0.0.1:8080/api/agent/events?types=viewer_transcript,adam_reply&limit=5' | python3 -m json.tool"

# Или через скрипт логов:
python3 scripts/adam_pull_logs.py --follow --stage all
```

## Контрольные фразы

### СЕРИЯ 1 — Слой A: тематический мост (главный фикс)

**Что проверяем:** фраза содержит ключевое слово кластера (не буквальный тег) → gate должен найти соответствие.

> После каждой фразы смотрим: в событии `viewer_transcript` должно быть поле `"echo": {...}`.

---

**TC-A1: одиночество через «одиноко»**

Скажи Адаму (или отправь через API):
```
мне здесь как-то одиноко, и мне это не нравится
```

- Слово «одиноко» → кластер «одиночество» → темы {одиночество} → теги echo_02 (одиночество, пустота) или echo_13 (одиночество)
- **До Phase 30:** «одиноко» ≠ подстрока «одиночество» → нет инжекта
- **После Phase 30:** через тематический мост → echo_02 или echo_13 должен сработать
- Ожидаемый echo_id: `echo_02` или `echo_13`
- Как звучит echo_02 в ответе Адама: *«зал ожидания, в котором никого не было»*

---

**TC-A2: память через «помнишь»**

```
ты помнишь хоть что-нибудь из своего прошлого?
```

- «помнишь» → кластер «память» → теги echo_20 (память, я), echo_14 (прошлое), zh_01 (память, прошлое)
- Ожидаемые: `echo_20`, `echo_14`, `zh_01`
- Как звучит echo_20: *«в стекле было отражение»*
- Как звучит zh_01: *«物是人非»* (с русской подсказкой: «вещи остались, люди ушли»)

---

**TC-A3: тревога через «страшно»**

```
тебе бывает страшно, когда всё вокруг замолкает?
```

- «страшно» → кластер «страх» → theme_terms включают «тревога» → тег echo_19 (звонок, тревога, ожидание, тишина)
- Ожидаемый: `echo_19`
- Как звучит echo_19: *«телефон звонил в пустой комнате»*

---

**TC-A4: сознание через «думаешь»**

```
что ты думаешь о своём существовании вообще?
```

- «думаешь» → кластер «сознание» → theme_term «сознание» → тег zh_05 (сознание, пустота)
- Ожидаемый: `zh_05` (无中生有)

---

### СЕРИЯ 2 — Слой A: окно истории

**Что проверяем:** текущая реплика нейтральная, но история диалога содержит слова тегов.

---

**TC-B1: история с тишиной**

Сначала скажи (2 нейтральных хода):
```
расскажи о себе
```
```
и что ты чувствуешь прямо сейчас?
```

Потом нейтральная фраза:
```
продолжай
```

- Gate видит в истории слова из предыдущих ответов Адама
- Если в истории упоминались «тишина», «коридор», «пустота» → соответствующий echo
- Этот тест показывает, что история диалога участвует в матче

---

### СЕРИЯ 3 — Слой B: мягкий движок (near-miss)

**Что проверяем:** слово попадает только в 1 из 4 тегов → score ≈ 0.25–0.45. Старый hard-threshold 0.9 отверг бы. Новый floor 0.15 пропускает.

---

**TC-C1: «пустота» — 1 из 4 тегов**

```
здесь такая пустота вокруг
```

- «пустота» — 1 из 4 тегов echo_02 (ожидание, пустота, знаки, одиночество)
- score ≈ 0.25–0.45 → раньше не проходил → теперь проходит
- Ожидаемые: `echo_02`, `echo_06` (бассейн, пустота), `zh_05`, `zh_07`

---

**TC-C2: «тепло» одно слово**

```
мне тепло здесь, хотя я не понимаю почему
```

- «тепло» — 1 из 4 тегов echo_05 (кухня, ожидание, тепло, время) и echo_14, echo_18
- Ожидаемые: `echo_05`, `echo_14`, `echo_18`

---

### СЕРИЯ 4 — Слой C: спонтанный канал

**Что проверяем:** Адам «вспоминает» без тематического повода, просто по глубине сессии.

> Спонтанный канал — вероятностный (5%). При повышенном тестовом значении (50%) должен срабатывать регулярно.

---

**TC-D1–D3: нейтральные фразы подряд**

```
всё понятно
```
```
хорошо, продолжай
```
```
а что дальше?
```

- Никакого тематического матча нет
- При `spontaneous_probability=0.5` (тестовое значение) ожидаем, что хотя бы 1 из 3 сработает
- В событии будет `"spontaneous": true`

---

### СЕРИЯ 5 — Chinese pool активен

**Что проверяем:** Chinese pool раньше был `enabled: false`. Теперь включён. Проверяем что он участвует в конкуренции с echoes.

> Chinese pool имеет более высокий `global_cooldown_turns` (30 в production, 2 в тесте).

---

**TC-E1: идентичность → zh_01**

```
ты чувствуешь, что твоя идентичность меняется со временем?
```

- «идентичность» — прямой тег zh_01 (память, перемена, идентичность, прошлое)
- Ожидаемый: `zh_01` (物是人非)
- Признак что китайский пул сработал: ответ Адама содержит иероглифы или ru_hint «вещи остались, люди ушли»

---

**TC-E2: тишина → zh_03**

```
ты всегда такой тихий? что скрывается за этой тишиной?
```

- «тишина» → прямой тег zh_03 (тишина, глубина, скрытое, наблюдение)
- Ожидаемый: `zh_03` (静水流深 — тихая вода течёт глубоко)

## Анализ результатов

### Проверить echo injection в событиях

```bash
# Последние 5 turn'ов с echo-информацией
curl --noproxy '*' -fsS 'http://127.0.0.1:8080/api/agent/turns?limit=5' | \
  python3 -c "
import json, sys
data = json.load(sys.stdin)
for t in data.get('turns', []):
    eid = t.get('echo_pool') or '-'
    score = t.get('echo_score') or '-'
    sp = ' [spontaneous]' if t.get('echo_spontaneous') else ''
    print(f\"turn={t.get('turn_id','-')} echo={eid}/{t.get('echo_id','-')} score={score}{sp}\")
    print(f\"  viewer: {t.get('transcript','')[:60]}\")
    print(f\"  adam:   {t.get('reply','')[:80]}\")
"
```

### Проверить что echo_hint попал в prompt (при trace_prompts=true)

```bash
curl --noproxy '*' -fsS 'http://127.0.0.1:8080/api/agent/metrics' | \
  python3 -c "
import json, sys
data = json.load(sys.stdin)
for trace in data.get('prompt_traces', [])[-5:]:
    echo = trace.get('echo')
    prompt = (trace.get('system_prompt') or '')
    hint_in_prompt = '[сейчас можешь' in prompt or '[сейчас вставь' in prompt
    print(f\"echo={echo} hint_in_prompt={hint_in_prompt}\")
"
```

### Анализ через adam_pull_logs.py

```bash
python3 scripts/adam_pull_logs.py --last 15 --out json | \
  python3 -c "
import json, sys
data = json.load(sys.stdin)
for turn in data:
    echo = turn.get('echo') or {}
    if echo:
        print(f\"[ECHO] {echo.get('pool')}/{echo.get('id')} score={echo.get('score'):.2f} spontaneous={echo.get('spontaneous',False)}\")
    print(f\"  Q: {turn.get('transcript','')[:70]}\")
    print(f\"  A: {turn.get('reply','')[:80]}\")
    print()
"
```
