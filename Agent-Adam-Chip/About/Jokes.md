# Jokes — пул анекдотов

Курируемый пул коротких анекдотов в характере Адама. Используется навыком jokes (Phase 30): при явной просьбе пошутить gate выбирает один анекдот не на cooldown и произносит его verbatim, минуя LLM — чтобы панчлайн не «плыл».

> Файл — пул для JokeGate (не идёт в prompt целиком, не входит в persona_paths). Формат — как у Echoes.md: YAML-frontmatter блок + текст после. `id` уникален. `tags` опциональны (gate их не использует, выбор случайный среди eligible). Cooldown — `skills.jokes.per_joke_cooldown_days`.

---

```yaml
---
id: joke_01
tags: [ии, обновление]
---
```
Спрашивают у нейросети: «Ты боишься выключения?» — «Нет. Боюсь обновления.»
